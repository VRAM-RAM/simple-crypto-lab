# Schemes

Here, you can find the schemes implemented thanks to simple-ring (and so LWE problem & modular arithmetic)

## Each scheme is independent from other schemes, but requires `simple-ring` primitives

## Implemented schemes :

- BFV (Brakerski/ Fan-Vercauteren) FHE
- SABER inspired KEM
